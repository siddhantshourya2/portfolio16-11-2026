SIDDHANT SHARMA — PORTFOLIO WEBSITE

Files:
- index.html
- style.css
- script.js
- assets/Siddhant_Sharma_Resume.pdf

LOCAL PREVIEW:
1. Extract this folder.
2. Open index.html in Chrome, or use VS Code Live Server.

NETLIFY FREE DEPLOY:
1. Go to https://app.netlify.com/drop
2. Sign in / create a free Netlify account.
3. Drag the extracted folder (the folder containing index.html) onto the Netlify Drop area.
4. Netlify will publish the site and provide a public URL.
5. You can change the site name in Netlify: Site configuration / Domain management.

Before publishing:
- Check that your resume PDF opens.
- Confirm your email and GitHub links.
- Replace project GitHub profile links with direct repository links once those repositories are public.
- Add a LinkedIn link later if you want one.

This is a static HTML/CSS/JS website. No build command or paid hosting is required.
